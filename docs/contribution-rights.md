# CEngine Contribution and Rights Policy (Interim)

CEngine is a proprietary KpnWorld-orchestrated project maintained under the KpnSolute GitHub organization.

Until a formal contribution agreement is approved:
- Only explicitly authorized maintainers should merge source changes.
- Do not treat a pull request as granting all intellectual-property rights automatically. For outside human contributions, verify that the contributor is authorized to submit the code and obtain appropriate written contribution/assignment terms before incorporating it.
- Human authorship, AI-assisted contributions, and material sourced from third parties must be reviewed for provenance and licensing.
- Customer-private plugins and records must not be copied into the shared CEngine repo or a future public template catalog.
- No external license to use CEngine commercially is implied by this document.

This is an interim project contribution policy, not a signed legal agreement.
